# Project Blueprint: Lotto Number Generator

## Overview
A simple, modern web application that generates random lotto numbers. It features a responsive design, dark/light mode toggle, and a partnership inquiry form.

## Current Features
- Random lotto number generation (1-45).
- Color-coded lotto balls based on number range.
- Dark and Light mode toggle with persistence using `localStorage`.
- Partnership inquiry form powered by Formspree.

## Planned Changes: Partnership Form
- Add a new section below the lotto generator for partnership inquiries.
- Use Formspree (endpoint: `https://formspree.io/f/xpqkvbwq`) for form handling.
- Style the form to match the existing dark/light mode themes.
- Include fields for Name, Email, and Message.
